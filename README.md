## Sorridere - Clínica Odontológica Premium

Website moderno e responsivo para clínica odontológica premium, com design sofisticado e foco em conversão.

### Tecnologias

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide Icons

### Desenvolvimento Local

```bash
npm install
npm run dev
```

O servidor de desenvolvimento estará disponível em `http://localhost:3000`

### Build

```bash
npm run build
```

### Deploy no Vercel

1. Conecte seu repositório ao Vercel
2. Configure as variáveis de ambiente (se necessário)
3. O Vercel detectará automaticamente as configurações do Vite
4. Deploy automático a cada push

Ou use a CLI do Vercel:

```bash
npm i -g vercel
vercel
```

### Preview

```bash
npm run preview
```
